# WisTrain-Cloud 智培云

基于权限联动的企业培训与第三方智能体集成系统。

## 项目简介

面向企业培训场景的管理后台：部门管理员创建内部培训项目并上传资料，员工加入项目完成学习；管理员录入第三方平台智能体 Key，快速生成独立智能体会话页面；员工按培训项目权限控制，完成学习解锁后才可使用对应智能体，实现「培训资料 + 配套 AI 助手」一体化管理。
